# Inline chat queue captures

Captured from the implemented application with isolated synthetic chats by
`integration-tests/tests/chromium/inline-queue.test.ts`.

- `desktop-compact.png`: single-line previews with an individual Steer action.
- `desktop-expanded.png`: expanded messages with Steer and direct editing.
- `desktop-menu.png`: Send now and Remove in the overflow menu.
- `mobile-expanded.png`: wrapped message text with actions below each message.
- `mobile-menu.png`: mobile overflow actions.
- `landscape-tall-composer.png`: a large queue and tall composer in a short pane.

The PR uses verified 72-hour Litterbox links when the upload service is available.
These committed captures preserve the evidence after temporary links expire.
