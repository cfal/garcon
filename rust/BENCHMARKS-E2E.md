# End-to-end benchmarks

User-level flows on the TypeScript original and behind the Rust front door, generated by `bun integration-tests/bench/e2e-benchmark.ts`. Unlike [BENCHMARKS.md](BENCHMARKS.md), which isolates single requests, these measure what a user waits for.

## Method

- Both controllers run at once in isolated integration fixtures with authentication, the production web build, and the scripted OpenAI-compatible provider, which replies deterministically. Each of 15 iterations runs every flow on both, in alternating order, after one unmeasured warm-up pass.
- A chat turn is timed from the start or run request until the turn terminal arrives on the WebSocket. Page loads use a fresh Chromium context (cold) and then a reload in it (warm), and are timed until the assistant reply is visible; the other page metrics are the browser's navigation timing.
